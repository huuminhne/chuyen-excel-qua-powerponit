# PowerPoint & Video Tỷ Giá

Cách chạy:
1. Mở `index.html` bằng Chrome hoặc Edge.
2. Tải file Excel hoặc bấm **Dùng mẫu có sẵn**.
3. Sửa nội dung nếu cần.
4. Bấm **Xuất PowerPoint** hoặc **Tạo video**.

Ghi chú:
- PowerPoint được tạo từ ảnh render để bám đúng mẫu và tránh lỗi căn lề.
- Video dùng `MediaRecorder`, nên trình duyệt tốt nhất là Chrome/Edge bản mới.
- Nếu bật nhạc nền, trình duyệt sẽ nạp `music-data.js` khi cần.
Nhạc nền: file `background-music.mp3` đã được thay bằng file bạn gửi.
